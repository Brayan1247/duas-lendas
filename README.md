# Duas Lendas

Site interativo sobre Stephen Curry e Aretha Franklin, feito com HTML, CSS e JavaScript.

## Páginas

- `index.html`: perfis
- `timeline.html`: linha do tempo
- `destaques.html`: destaques
- `quiz.html`: quiz
- `player.html`: player

## Executar localmente

Abra `index.html` no navegador ou inicie um servidor estático na pasta do projeto:

```bash
python3 -m http.server 8000
```

Depois, acesse <http://localhost:8000>.
